# 🚀 Crypto Market Scenario Simulation Model

A short-term simulation and prediction model for cryptocurrency markets using XGBoost and log-return time series data.

## 📌 Description  
This project aims to simulate and forecast crypto market behavior under different scenarios. We apply the XGBoost model to log-return time series data in order to:  
- Predict short-term price movements  
- Assess potential risk metrics  
- Support portfolio decision-making for investors
